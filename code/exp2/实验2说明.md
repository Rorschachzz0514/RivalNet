## 2. 数据

- 样本：`subsets/pred_v2/samples.parquet`（与实验 1 相同；训练 2017–2019 / 验证 2020 / 测试 2021）。
- 竞争集合：`subsets/pred_v2/rivals.parquet`（`data_pipeline/31`），每篇论文在 T 时可见的最相似 50 篇（Y−2～Y 年），带关系特征。
- **份额的分母（"格子"）**：同一训练期子课题（只用 ≤ 2019 年论文聚类，K = 2000）、同一年份的全部样本论文。格子的真实总被引 = 格内论文逐年被引之和。

## 3. 模型（预先登记）

**MPC-Net**：被引均值 μ_{i,t} = Â_{g,t} × s_{i,t}，t = 第 1、2、3 年。

| 模块 | 输入 | 做法 |
|---|---|---|
| ① 需求塔 Â | 格子层面：格内论文数（T 时已知）、子课题与方向的供给 / 流入量 / 参考文献数历史、增长率、年份差无关的特征 | MLP 输出 3 年的 log 总量；损失：格子总被引的负二项负对数似然 |
| ② 论文编码器 | SPECTER2（768）+ 论文元数据、作者历史、T 时渠道（同实验 1 L1 的特征）+ 第二方向热度 | MLP → h_i |
| ③ 竞争模块 | 50 个对手：对手向量、相似度、年份差、天数差、对手截至 T 的被引、渠道、共同作者、文献耦合、互引 | 以 h_i 为查询的多头交叉注意力 → z_i；对手效应不限符号 |
| ⑥ 份额头 | [h_i, z_i] | 每年一个 logit；格内 softmax → 份额 s；浓度 α_g（由格子特征预测，正数）；损失：格内被引的 **Dirichlet-多项** 负对数似然（以格子真实总数为条件） |

总损失 = 需求塔 NLL + 份额 DM-NLL（逐年相加）。验证集早停（指标：验证集 MALE），5 个随机种子，报告均值 ± 标准差。

**对比方法**：D0、D1-方向+子课题、D1*-子课题（上帝视角）、LightGBM L4、MLP-文本、NAIP（全部来自实验 1，同一测试集）。

**消融（实验 3，必做）**：
| 编号 | 改动 |
|---|---|
| A1 | 去掉"总量 × 份额"分解：直接用 [h_i, z_i] 回归逐年 log 被引（负二项损失） |
| A2 | 需求塔换成真实格子总量（上帝视角上界） |
| A3 | 去掉竞争模块 ③ |
| A7 | Dirichlet-多项 → 普通多项（无浓度 α） |
| A11 | 交叉注意力 → 对手特征简单平均 |
| A13 | 负二项 / DM 损失 → 对 log1p 被引的均方误差（同结构） |
| A17 | 竞争集合只保留文献耦合对手 / 只保留前 10 名 |

## 4. 指标与判定（预先登记）

指标同实验 1（MALE、RMSLE、MAE、RMSE；方向内 / 子课题内 Spearman；子课题内 NDCG@10；份额 L1），另报告逐年 MALE。

| 编号 | 问题 | 通过标准（测试集，5 个种子均值） |
|---|---|---|
| P1 | MPC-Net 是否比最好的对比方法更准 | MALE 低于最好的非上帝视角对比方法，且按子课题重抽样的差异 95% 区间不含 0 |
| P2 | 组内区分是否更好 | 子课题内 Spearman 高于最好的非上帝视角对比方法（同上） |
| P3 | 分解是否有用 | A1 的 MALE 显著高于完整模型 |
| P4 | 竞争模块是否有用 | A3 的子课题内 Spearman 显著低于完整模型 |

结果怎么用：P1、P2 都通过 → 主表；只通过 P2 → 卖点放在组内排序与可解释性；都不通过 → 按设计文档风险表，卖点转向 C1 与可解释性。

## 8. 第七轮：由研究设想推出的新结构（2026-10-03，只看验证集）

用户要求："基于研究设想与实验结果，自行探索设想能够解释的模型结构作为创新点"。每个结构都对应设想中的一个机制，并先在验证集上与当前最好配置 AS_r06_1 **同种子配对**比较（`09_innovate.py`，结果追加在 `innov/rounds.md`）。全部开关默认关闭；新模块在旧模块之后创建，旧配置的参数初始化顺序不变（冒烟检验：AS_r06_1 第 1 轮训练损失与原记录逐位相同 43.4086，验证 MALE 差 0.0003，来自 GPU 非确定性）。

| 开关 | 对应的设想 | 结构 |
|---|---|---|
| `rel_rival` | 竞争取决于"和对手比谁强"（设计文档 1.6：在对手中比） | 对手编码加入 [对手 − 自己, 对手 ⊙ 自己] |
| `two_chan` | 替代与互补并存（1.4；实验 0 撞车后发 −14%、实验 5 溢出 +8%） | 两个注意力通道："替代"效应 ≤ 0、"互补 / 可见度"效应 ≥ 0，作为带符号的标量直接加到 log 预测上；`strict` = 只通过这两个标量（可解释分解），`plus` = 通道向量也进入预测头 |
| `luce` | 份额 = 自身吸引力 / 竞争集合总吸引力（1.5，市场份额的吸引力模型） | 显式项 −γ·log(1 + Σ_j σ_ij·e^{q_j − q_i})，q 为吸引力，σ_ij 为由相似度、年份差、文献耦合等决定的可替代程度，γ ≥ 0 |
| `cohort` | 同子课题同年的论文分同一份需求（1.2、1.5） | 同格子论文之间的自注意力层（只用发表时可见的特征） |
| `xdom` | 跨域竞争：一篇论文同时参与多个方向（0.2 的 C2、实验 0 第二方向拥挤 −5%） | 取向量最接近的 3 个其他子课题同年的格子需求嵌入，按相似度（可学温度）加权 |

保存的可解释量：`preds.parquet` 中 `part_subst`、`part_compl`、`part_luce`（每篇论文的替代损失、互补收益、吸引力份额项）。
判定：只看验证集；一个结构"有用" = 4 个种子配对 ΔMALE < 0 且超过约 2 个标准误，或子课题内 Spearman 明显提高。最终方案确定后才在测试集上评价一次。

### 8.1 第七轮结果（详见 `innov/rounds.md`、`innov/reflections.md`）

| 轮 | 做了什么 | 结果 |
|---|---|---|
| r1 | 5 个新结构各自加在 AS_r06_1 上（原训练方式：验证集早停），4 种子配对 | 全部略差（ΔMALE +0.002～+0.006）；发现验证误差逐轮跳动 0.67↔0.77，比较被"早停运气"主导 |
| r2 | 改为固定 30 轮 + 最后 5 轮权重平均（SWA），重比 | SWA 模型对 2020 年整体高估 +0.15；扣掉整体偏差后各版本相差约 0.002；双通道严格版、同期竞争层在 SWA 下略好（−0.002） |
| r3 | 结构组合、两层同期竞争层、10 轮平均；结构多样性集成；机制检验 | 组合无提升或不稳定；多结构集成在早停训练下与同结构集成相同（去偏 0.6620 vs 0.6620） |

**误差来源**：落在日历年 2022 年及以后的被引普遍偏低（2021 届第 1 年平均 2.90，2019、2020 届为 4.63、4.53），测试集真实 log 均值 1.536，低于验证集 1.719；这是 T 时看不到的整体需求冲击，竞争结构无法修正。
验证集（2020 届，窗口 2021–2023）与测试集（2021 届，窗口 2022–2024）的被引窗口有重叠，早停与"加 2020 年重训"会间接吸收这一冲击；所有对比方法同样使用验证集，论文中需说明。

**机制检验**：双通道严格版中"替代"通道几乎为 0，"互补 / 可见度"通道与相似论文数（Spearman +0.37～+0.44）、对手已有被引（+0.42）正相关 →
在预测意义上，相似论文的净作用是带来可见度；替代效应在横截面预测中识别不出，只在撞车对等准实验设计中出现（实验 0：后发 −14%）。

**判定**：竞争结构已到平台期，终版方案不变（AS_r06_1，A + B 集成；测试 MALE 0.6745、子课题内 Spearman 0.644）。双通道严格版作为可解释变体用于实验 4（不损失准确率，给出每篇论文的可见度收益）。
测试集数字（事后报告，未用于选择）见 `innov/ens_check_test.py` 输出：新结构不改变排序准确度（0.631–0.634 vs 0.633）。

## 9. 与 DPPDCC（CIKM 2024）的比较（2026-10-03，`10_dppdcc_compare.py`，`results/实验2结果_DPPDCC比较.md`）

- 口径：DPPDCC 的标签是语料内被引（Y+1～Y+3 年之和）；MPC-Net 在同一口径上重训（DP_full = 2017–2019 训练；DP_2019 = 与 DPPDCC 相同只用 2019 年训练），各 5 种子。
- DPPDCC：官方代码，严格冷启动划分（2019 训练 / 2020 验证 / 2021 测试），5 轮，验证集最优为第 4 轮（验证 MALE 0.5959）；兼容性修改 9 项见 `third_party/DPPDCC/MPCC_COMPAT_PATCHES.md`。
  官方测试会在测试集上挑检查点，我们只用按验证集选出的全局最优检查点。结果文件的行名是内部节点编号，经 `sample_node_trans.json` 换回论文 ID 后，DPPDCC 记录的真实值与我们的标签在 84,566 篇上完全一致。
  测试名单含 2019、2020 年论文（DPPDCC 的实现要求），这些论文在 2021 年快照中已能看到自己的部分目标被引，预测严重偏大（官方整体 MALE 1.10 即由此而来）；只评价 2021 年论文，不受影响。
- 信息差异（如实说明）：DPPDCC 在 2021 年快照中能看到 2021 年论文发表当年收到的被引（y0）；MPC-Net 的冷启动设定不用 y0。

| 模型（2021 年论文，84,566 篇） | MALE | RMSLE | 子课题内 Spearman | NDCG@10 |
|---|---|---|---|---|
| DPPDCC | 0.5953 | 0.7613 | 0.546 | 0.687 |
| MPC-Net（2017–2019，5 种子集成） | 0.5930 | 0.7805 | 0.597 | 0.700 |
| MPC-Net（只用 2019，5 种子集成） | 0.5903 | 0.7703 | 0.590 | 0.695 |
| MPC-Net（2017–2019，单种子均值） | 0.6007 | 0.7903 | 0.591 | 0.695 |

按子课题重抽样：MALE 与 DPPDCC 基本持平（2017–2019 集成 −0.002，区间含 0；只用 2019 集成 −0.005，显著）；**子课题内 Spearman 显著更高（+0.051 / +0.044）**。
RMSLE 上 DPPDCC 更好（MPC-Net 用 Huber 损失，偏向中位数；RMSLE 偏向均值）。耗时：DPPDCC 预处理约 2 小时 + 每轮训练约 13 分钟；MPC-Net 单模型约 6 分钟。
