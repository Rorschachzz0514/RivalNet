## 2. 预先登记

### 5-2 强对手出现事件

- **样本**：实验 2 的样本表中首次公开年份 Y ∈ {2017, 2018, 2019} 的论文（主分析集）。
- **强对手事件**：之后第 1 或第 2 个日历年（E = Y+1 或 Y+2）首次公开的样本论文 k，满足：与 i 的 SPECTER2 相似度 ≥ 0.95；k 没有引用 i（排除"跟随者"）；与 i 没有共同作者；k 第一个完整年份的被引在"同一主方向、同一年份"的论文中处于前 5%。i 的事件年份 = 最早的强对手年份。
- **主分析**：E = Y+2 的事件（有两个事件前时期：t = Y、Y+1）。相对时间 r = t − E ∈ {−2, −1, 0, 1, 2, 3}，以 r = −1 为基准。
- **对照组**：同一子课题（K = 2000）、同一年份、同一发表渠道类别，且在 Y+1、Y+2 都没有强对手事件的论文；按事件前两年的被引 (log1p c_Y, log1p c_{Y+1}) 最近邻匹配 3 篇（可放回），距离 ≤ 0.3。对照论文的"事件年份"同样记为 Y+2。
- **模型**：log1p(c_{u,t}) ~ Σ_{r≠−1} β_r·处理组×1[r] + 论文固定效应 + 匹配组×相对时间固定效应，标准误按匹配组聚类；另做 Poisson 版本与"处理×事件后"单一系数版本。
- **通过标准**：事件后平均效应（单一系数）< 0 且 p < 0.05；且事件前 β_{−2} 不显著（p > 0.1）。
- **稳健**：E = Y+1 的事件（只有一个事件前时期，不做事前趋势检验）；强对手阈值前 10% / 前 1%；相似度 ≥ 0.97。
- **解读预案**：若事件后效应为正，说明强相似论文的出现带来的可见度 / 互补效应大于抢夺效应（与实验 0 v2"相似论文多 → 被引多"一致），如实报告。

### 5-3 模型内假对手

- 用实验 2 定版模型（MPCNet5_l1，5 个种子的已训练权重），在测试集上把每篇论文的竞争集合（对手向量 + 关系特征 + 掩码）**整体换成同一格子（子课题 × 年份）里另一篇随机论文的竞争集合**（`shuffle_cell`），以及换成测试集任意另一篇论文的（`shuffle_all`）。模型参数不变。
- **通过标准**：`shuffle_cell` 下子课题内 Spearman 比真实对手显著下降（按子课题重抽样，差异 95% 区间不含 0）——说明模型用的是"这篇论文自己的对手"，而不只是"它所在子课题的热度"。

### 5-4 ICLR 审稿分（质量锚点）——写于运行 03 之前

- **数据**：OpenReview 接口需要人机验证，不绕过；改用 NAIP 作者公开的 NAIDv2（GitHub 仓库 `ssocean/NAIP` 的 `v2_resource/NAIDv2`，ICLR 2021–2025 投稿的标题、摘要、各审稿人分数（归一化到 0–1）、录用结果）。按规范化标题完全匹配到实验 2 的样本：1,276 篇（2020 年 527 篇 = 验证集，2021 年 734 篇 = 测试集）。
- **变量**：审稿平均分 rating、是否录用 accept；MPC-Net 定版模型（5 个种子平均）的预测 pred_full；去掉对手的消融模型 B_no_rivals 的预测 pred_nr；**竞争贡献** = pred_full − pred_nr。
- **5-4a（主）**：OLS log1p(y3) ~ rating + accept + 年份 + pred_nr + 竞争贡献，稳健标准误。**通过标准**：竞争贡献的系数 > 0 且 p < 0.05（控制质量与"无竞争"预测后，竞争信息仍能解释被引）。
- **5-4b（描述）**：pred_full 与 rating 的 Spearman 相关（预期低到中等）。
- **5-4c（描述）**：审稿分相近（分五档 × 年份固定效应）时，log1p(前一年相似论文数) 与"是否已被抢先"对 log1p(y3) 的系数。
