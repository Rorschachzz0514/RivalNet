# 实验 1 说明：评价诊断 C1 —— 现有评价指标测的是论文，还是方向热度

> 对应设计文档 `MPCC/EXPERIMENT_DESIGN_1.md` 第 4 节；根据实验 0 v2 的结果重新设计（2026-10-02）。
> 本目录：`MPCC/Eperiment/Experiment_1/`。脚本在服务器 `/path/to/mpcc/exp1/` 运行，结果同步回 `results/`。
> **第 3、4 节写于运行任何实验 1 脚本之前（预先登记）**，之后不改；事后追加的分析单独标注。

## 1. 要回答的问题

引用预测论文普遍用"绝对被引数的误差"（MALE、RMSLE、MAE、RMSE）评价模型。这些指标的高低，主要取决于模型是否猜对了**方向 / 子课题整体有多热**，还是取决于模型是否分清了**同一方向内哪篇论文更好**？

实验 0 v2 的结论使这个问题更重要：被引的高低和"一小片研究有多热"强相关（相似论文越多被引越多），所以只要猜对热度，绝对误差就会变小，而这不代表模型懂得区分论文。

## 2. 数据

预测样本表 `subsets/pred_v2/samples.parquet`（脚本 `data_pipeline/30_pred_samples.py`），一行一篇焦点论文（实验 0 v2 主分析集：期刊 / 会议 / 论文集 / arXiv），313,260 篇。

| 切分 | 首次公开年份 | 篇数 | 预测的被引年份 |
|---|---|---|---|
| 训练 | 2017–2019 | 155,294 | 发表后第 1–3 年 |
| 验证 | 2020 | 73,400 | 2021–2023 |
| 测试 | 2021 | 84,566 | 2022–2024 |

- **预测时间点 T**：首次公开年份 Y 的年底。冷启动不使用焦点论文自身的任何被引。所有"历史"特征只用 ≤ Y 年已发生的被引；发表渠道按 T 时已有的版本（之后才正式发表的论文在 T 时记为预印本）；训练期子课题只用 ≤ 2019 年的论文聚类。
- **目标**：主目标 `y3` = Y+1～Y+3 年被引之和，在 log1p 空间评价；另报告逐年目标。
- **评价分组**（只用于评价）：OpenAlex 主方向 × 年份（"方向"）；全数据 SPECTER2 子课题 K = 2000 × 年份（"子课题"）。测试集只有 2021 一年，所以分组 = 方向 / 子课题。

## 3. 模型（预先登记）

| 类别 | 名称 | 做法 | 知道什么 |
|---|---|---|---|
| 傻模型 | **D0 全局延续** | 预测值 = 截至 T 已完整观测的最近队列（Y−3）全部样本论文的平均 log1p(y3) | 只知道"今年大概多少" |
| 傻模型 | **D1-方向** | 线性回归，只用方向层面的历史特征（方向 Y−3 队列平均 log1p(y3)、Y−1 队列第一年平均、方向供给 / 施引方规模 / 流入量及其增长），训练集拟合 | 方向热度；同一方向内所有论文预测相同 |
| 傻模型 | **D1-子课题** | 同上，只用训练期子课题层面的历史特征 | 子课题热度 |
| 傻模型 | **D1-方向+子课题** | 两者特征合并 | 方向 + 子课题热度 |
| 傻模型（上帝视角） | **D1\*-方向 / D1\*-子课题** | 预测值 = 测试集里该方向 / 子课题论文**真实**的平均 log1p(y3)（偷看答案，只作上界） | 完美的热度，对论文一无所知 |
| 傻模型 | **D3 = D1-方向+子课题 + 随机扰动** | 加正态噪声（标准差 0.3） | 热度；组内顺序完全随机 |
| 学习模型 | **L1 元数据** | LightGBM：论文自身元数据 + T 时渠道 + 作者历史 + 渠道历史（不含方向 / 子课题热度、文本、竞争） | 论文与作者 |
| 学习模型 | **L2 元数据 + 热度** | L1 + 方向 / 子课题历史特征 | + 热度 |
| 学习模型 | **L3 + 文本** | L2 + SPECTER2 主成分（64 维，PCA 只在训练集拟合） | + 内容 |
| 学习模型 | **L4 + 竞争** | L3 + 竞争特征（前一 / 两年相似论文数、对手截至 T 的被引、文献耦合对手数、是否已被抢先） | + 竞争 |
| 学习模型 | **MLP-文本** | 多层感知机：SPECTER2 768 维 + 标准化后的 L4 数值特征，GPU 训练，验证集早停 | 同 L4 |
| 已发表方法 | **NAIP（AAAI 2025）** | 官方发布的 LLaMA-3-8B 微调权重，只读标题 + 摘要输出 0–1 分；在验证集（2020）上做保序回归映射到 log1p(y3)，再用于测试集 | 文本 |

LightGBM 统一在验证集上早停（目标 log1p(y3)，L2 损失），超参数固定（不在测试集上调）。"发表 1 年后"设定另做：目标 log1p(y2 + y3a)，傻模型 D2 = log1p(y1) + 方向 Y−2 队列中 [log1p(第 2、3 年被引) − log1p(第 1 年被引)] 的平均值；学习模型 = L4 + log1p(y1)。

## 4. 指标与假设（预先登记）

**指标**（测试集 2021）：
- 绝对误差：MALE = 平均 |log1p(ŷ) − log1p(y)|；RMSLE；原始计数的 MAE、RMSE（y3）。
- 组内排序：方向内 / 子课题内 Spearman（每组 ≥ 10 篇，按组大小加权平均）；组内 NDCG@10（每组 ≥ 20 篇，增益 = y3）；全体 Spearman。
- 份额误差：组内预测份额 ŷ/Σŷ 与真实份额 y/Σy 的 L1 距离（每组 ≥ 10 篇且 Σy > 0，0–2，越小越好），按组平均。
- 置信区间：按组（子课题）有放回重抽样 1,000 次。

**假设与判定标准**：

| 编号 | 假设 | 通过标准 |
|---|---|---|
| **C1-a** | 只知道"完美热度"的傻模型在绝对误差上能赢过学习模型 | D1\*-子课题的 MALE ≤ 最好学习模型的 MALE |
| **C1-b** | 只用 T 时可得的热度信息的傻模型，在绝对误差上和学习模型差不多 | D1-方向+子课题的 MALE ≤ 1.10 × 最好学习模型的 MALE |
| **C1-c** | 存在"排序颠倒"：绝对误差更好的模型，组内排序反而更差 | 存在一对模型 A、B，A 的 MALE 显著更低而子课题内 Spearman 显著更低（两项差异的 95% 置信区间都不含 0） |
| **C1-d** | 绝对误差与组内排序给出的模型排名不一致 | 所有模型按 MALE 的排名与按子课题内 Spearman 的排名之间 Kendall τ < 0.5（描述性） |

另报告：log1p(y3) 的方差分解（方向 × 年份之间 / 子课题 × 年份之间 / 组内，在全部样本与每个年份上）。

**结果怎么用**：C1-a、C1-b 至少一项通过且 C1-c 通过 → C1 作为论文的独立贡献（主表 = 傻模型 vs 学习模型 vs NAIP 两类指标）；都不通过 → C1 降级为"评价时应同时报告组内排序"的建议，主卖点转向实验 2。
