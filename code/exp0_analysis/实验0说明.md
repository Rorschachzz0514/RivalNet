## 1. 要回答的问题

同方向、同一时期的论文放在一起比较，**发表前已经有很多"撞题"论文的那一篇，之后 3 年的被引是不是更少？**
这是整篇论文（竞争份额模型 MPC-Net）的立项前提：如果论文之间不存在对引用的竞争，"份额"建模就没有意义。

## 3. 变量定义

### 3.1 因变量

| 变量 | 定义 |
|---|---|
| `y3`（主） | 发表后第 1–3 个完整年份的被引之和：首次公开年份为 Y，统计 Y+1、Y+2、Y+3 年的被引（不含发表当年，避免发表月份不同造成差异）。2021 年发表的论文恰好统计到 2024 年 |
| `y3_in_corpus` | 同窗口内、只算 AI 样本内施引论文的被引（稳健性） |

### 3.2 竞争变量（核心解释变量）

| 变量 | 定义 | 来源 |
|---|---|---|
| `prior_s2_{τ}`（主：τ = 0.95） | 发表前 365 天内、SPECTER2 相似度 ≥ τ 的样本论文数（不限方向） | `sim_counts` |
| `prior_s2_{τ}_same` | 同上，仅限同一主方向 | `sim_counts` |
| `prior_s3` | 发表前 365 天内、文献耦合对手数（共享参考文献 ≥3 且 Jaccard ≥5%） | `pairs`（`found_by_s3`、`days_after_focal`） |
| `prior_s3_strict` | 同上，仅限互不引用的对手 | `pairs` |
| `n_prior_cited` | 焦点论文引用了多少篇发表前的相似论文（S2 τ 或 S3）——控制变量，区分"引用前人"与"被前人抢走" | `pairs` |

**阈值 τ 的依据**（`_sim_calibration.json`）：随机同方向同时期论文对的 SPECTER2 相似度中位数 0.868、p99 0.935、p99.9 0.955。主结果取 τ = 0.95（约为随机同方向对的 p99.9），敏感性分析覆盖 0.90–0.98。

### 3.3 控制变量（论文层面）

`log(n_authors)`、`log1p(n_institutions)`、`log(n_refs)`、`any_oa`（任一版本开放获取）、`has_abstract`、`has_funding`、`has_preprint`；固定效应：方向 × 年份。

### 3.4 宏观层面（方向 × 年份）

| 变量 | 定义 |
|---|---|
| `cohort_y3` | 该方向该年全部焦点论文的 `y3` 之和（因变量） |
| `supply` | 该方向该年的论文数（`n_ai_dedup`，与样本同口径） |
| `demand_followers`（主） | 该方向在 Y+1～Y+3 年新论文的参考文献总数（"有多少人在写参考文献"）。不含这批论文自己收到的被引，避免与因变量机械相关 |
| `demand_inflow_net` | 该方向全部论文在 Y+1～Y+3 年收到的被引之和，**减去这批论文自身的被引**（稳健性） |

## 4. 六个检验

| 编号 | 检验 | 做法 | 通过标准 |
|---|---|---|---|
| **0-1 宏观** | 方向内论文变多，是否摊薄每篇的被引 | 一行 = 方向 × 年份（385 格）。Poisson：`cohort_y3 ~ log(supply) + log(demand)` + 年份固定效应；另做一版加方向固定效应 | 供给系数 b < 1 且显著（b = 1 互不影响，b = 0 完全零和） |
| **0-2 微观** | 撞题对手多的论文是否被引更少 | 一行 = 焦点论文。Poisson：`y3 ~ log1p(prior_s2_0.95) + 控制变量` + 方向 × 年份固定效应；OLS：`log1p(y3)` 同上。标准误按方向聚类 | 系数为负且显著（Poisson 与 OLS 都满足） |
| **0-3 稳健** | 换一种找对手的方法结论是否一致 | 分别用 S2（不同阈值、只限同方向）与 S3（全部 / 只限互不引用）重做 0-2 | 方向一致 |
| **0-4 假对手** | 效应是不是巧合 | 在同一方向 × 年份内随机打乱对手数，重复 200 次，得到系数的置换分布 | 真实系数落在置换分布 95% 范围之外 |
| **0-5 撞车** | 几乎同时做出同一成果，后发表者是否吃亏 | 相似度 ≥ 0.97、首次公开相差 ≤ 183 天、互不引用、两篇都是焦点论文的论文对：比较后发表者与先发表者的 `y3`；按时间差分组 | 后发表者显著更少（参照 Hill & Stein 2025：少 21%）。**需人工核验**，脚本输出候选清单 |
| **0-6 跨域** | 第二、第三方向的拥挤是否也有影响 | 有 ≥2 个方向的焦点论文：在 0-2 基础上加入第二方向的供给 `log(n_rule)`（含 AI 以外的方向），控制主方向 × 年份固定效应 | 系数为负且显著 |

**结果怎么用**（设计文档 3.4 节）：4 项及以上通过 → 按原计划推进；0-1 的 b 接近 0 → 份额加起来等于 1 的 Dirichlet 头合理；b 在 0–1 之间 → 需加"流向集合外"选项；1 项及以下通过 → 启用后备方案。
