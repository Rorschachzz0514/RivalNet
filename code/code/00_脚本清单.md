# 数据处理脚本清单（MPCC）

> 所有数据处理都由下面这些编号脚本完成，按编号顺序执行即可从 OpenAlex 原始快照完整复现全部数据。
> 每个脚本开头都有统一格式的说明：用途、输入、输出文件、用法、运行记录。
> 本地编辑（`MPCC/data_pipeline/`），上传到服务器 `/path/to/mpcc/code/` 运行；运行日志在服务器 `/path/to/mpcc/logs/`，本地存档在 `data_pipeline/logs/`。
> 数据的详细说明（字段字典、规则、规模、已知问题）见 `数据说明_总库与各实验子集.md`。

## 编号规则

第一位数字 = 阶段（1 总库，2 实验 0，3 实验 1 …），第二位 = 阶段内执行顺序。

## 辅助工具（`tools/`，服务器 `/path/to/mpcc/code/`）

| 脚本 | 做什么 |
|---|---|
| `tools/start_bg.sh` | 后台启动任务，进程组 ID 写入 `logs/<名称>.pid`，停止用 `kill -- -$(cat logs/<名称>.pid)`（避免按名字搜进程误杀） |
| `tools/run_exp0_after_check.sh` | 等【14】完整检查结束后再启动【20】（两者都大量读盘，不同时跑） |
| `tools/run_exp0_pairs.sh` | 【22】收尾后同时启动【24】（GPU）与【23】（CPU） |
