## 1. 为什么这样设计

定版模型（MPCNet5_l1）没有显式的"总量 × 份额"乘法结构，原设计里的浓度参数 α、份额分解等解释量不再直接可得。最能回答"模型从对手那里学到了什么"的量是：

> **竞争贡献** c_i = 定版模型的预测 − 去掉竞争模块的消融模型（B_no_rivals）的预测（log1p 空间，5 个种子各自平均后相减）。

c_i > 0：对手信息让模型**调高**了这篇论文的预期被引（对手更像"互补 / 可见度"）；c_i < 0：**调低**（更像"替代 / 被抢"）。实验 5-4 已证明 c_i 在控制 ICLR 审稿分后仍能解释被引。

## 2. 分析（预先登记）

| 编号 | 分析 | 做法 | 预期 |
|---|---|---|---|
| 4-1 | 竞争贡献的分布 | 测试集 c_i 的分布；c_i > 0 / < 0 的比例；按实际被引分档 | 两个方向都有，正的更多（与实验 0 v2、5-2 一致） |
| 4-2 | 什么样的对手让模型加分 / 减分 | c_i 对竞争集合描述量回归（标准化，子课题固定效应）：最相似 10 个的平均相似度、前一年 / 同年对手数、对手截至 T 的累计被引（平均 / 最大）、文献耦合比例、共同作者比例、焦点引用对手比例、已被抢先 | 已被抢先、同年高相似对手 → 负；强对手（累计被引高）、焦点引用的对手（站在前人肩上）→ 正 |
| 4-3 | 互补 vs 替代（事后检验，用到未来信息，只用于解释） | 计算每篇测试论文与其 50 个对手**之后被同一篇论文共同引用**的比例；看它与 c_i 的关系 | 共被引比例高（互补）→ c_i 更高 |
| 4-5 | 不平等程度的校准 | 子课题内预测被引（expm1(pred)）与真实被引的基尼系数对比，多个模型 | 点预测都会低估不平等；MPC-Net 应更接近真实 |
| 4-7 | 个案 | c_i 最负 / 最正、且被引不为零的论文各 3 篇：标题、最相似的 3 个对手、真实被引、两种预测 | 用于论文的案例说明 |
